# ALPR-Atlas
ALPR (automatic license plate reader) node data from the Overpass API published in the ExCam format.

---

Locations of automatic license plate reader (ALPR) cameras in the United States
and its territories, from OpenStreetMap, in the ExCam format.

**Download the latest file:**
https://github.com/ludensdriver/ALPR-Atlas/releases/latest/download/US.excam

Updated weekly. Older versions are on the Releases page.
